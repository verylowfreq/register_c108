# コミケ簡易レジ (register_c108)

コミックマーケット **C108** のブース会計を、スマホ・タブレットで完結できる簡易レジ（POS）です。
サーバ不要・ビルド不要の**完全クライアントサイド**な静的サイトで、データはブラウザの `localStorage` に保存します。GitHub Pages でそのまま公開できます。

## 特長

- 📱 モバイル・タブレット優先のレスポンシブUI（PCでも閲覧可）。大きめのタップ操作向けボタン。
- 🧾 会計フロー: **商品と個数を選ぶ → 合計確認 → 受取金額入力 → 釣銭自動計算 → 確定**。
- 👤 会計担当者（A / B / C）を記録。担当者は次の会計へ**引き継ぎ**（確定してもリセットしない）。
- 📊 会計件数・売上合計・担当者別集計を表示。
- 📥 **CSVダウンロード**（UTF-8 BOM 付きで Excel でも文字化けしない）。
- 📴 **オフライン動作**（Service Worker）。一度開けば、ネット切断でも起動・会計・CSV出力まで可能。
- ➕ **PWA対応**（ホーム画面に追加してアプリのように使える）。

## 会計の流れ

1. 画面上部で **担当者（A/B/C）** を選ぶ（一度選べば維持されます）。
2. **レジ**タブで商品をタップしてカートに追加。カート内の `＋ / −` で個数を調整。
3. 合計を確認して **「会計へ」**。
4. テンキーで **お預かり金額**を入力（`ちょうど` / `+500` / `+1000` / `+5000` のクイックボタンも利用可）。
5. **おつり**が自動計算されます（不足時は赤字表示で確定できません）。
6. **「確定」** で会計を記録。カートは空になり、担当者はそのまま維持されます。
7. **履歴**タブで集計確認・CSVダウンロードができます。

## 当日の商品データに差し替える手順

商品は `docs/products.js` の `window.PRODUCTS` 配列で定義しています。当日はこのファイルを編集してください。

```js
window.PRODUCTS = [
  { id: "p01", name: "新刊イラスト本", desc: "B5フルカラー32P", price: 1000, image: "images/p01.svg" },
  // ...
];
```

- `id` : 商品ごとに**重複しない**一意のID。
- `name` : 商品名。
- `desc` : 説明（詳細ボタンで表示。空文字でも可）。
- `price` : 値段（**円・整数**）。
- `image` : 写真のパス。**省略・空文字でも動作**します（無い場合や読み込み失敗時は商品名の頭文字タイルを表示）。

### 写真を差し替える

1. 商品写真を `docs/images/` に置きます（例: `docs/images/p01.jpg`）。
2. `products.js` の該当商品の `image` にそのパスを指定します（例: `image: "images/p01.jpg"`）。

> 初期状態では色付きのプレースホルダSVG（`docs/images/p01.svg` 〜 `p08.svg`）を同梱しています。差し替え前提のサンプルです。

> **オフライン用キャッシュについて**: 画像やコードを差し替えたら、`docs/sw.js` 冒頭の `CACHE_NAME`（`register_c108_CACHE_v1`）のバージョン番号を上げてください。端末側の古いキャッシュが破棄され、新しいアセットが読み込まれます。

## GitHub Pages で公開する

1. このリポジトリの **Settings → Pages** を開く。
2. **Build and deployment → Source** を **Deploy from a branch** に設定。
3. **Branch** を **`main`** / フォルダを **`/docs`** に設定して **Save**。
4. 数十秒〜数分後、`https://<ユーザー名>.github.io/register_c108/` で公開されます。

## ローカルで動作確認する

ファイルを直接開いても概ね動きますが、Service Worker を含めて確認するにはローカルサーバ経由が確実です。

```bash
cd docs
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## CSV の形式

会計明細は「**商品1種ごとに1行**」で出力されます（集計しやすい形）。文字コードは UTF-8（BOM付き）。

| 列 | 内容 |
|----|------|
| `transaction_id` | 会計ID |
| `datetime` | ISO8601（ローカル時刻・オフセット付き 例 `+09:00`） |
| `cashier` | 担当者 A/B/C |
| `product_id` | 商品ID |
| `product_name` | 商品名 |
| `unit_price` | 単価 |
| `quantity` | 個数 |
| `line_subtotal` | 行小計 |
| `transaction_total` | その会計の合計 |
| `received` | お預かり金額 |
| `change` | おつり |

ファイル名: `register_c108_sales_YYYYMMDD_HHMMSS.csv`

## データについての注意

- 会計履歴・担当者は**その端末・そのブラウザの `localStorage`** に保存されます。
- **端末やブラウザを変えると履歴は共有されません**。会計は1台の端末に統一するのがおすすめです。
- ブラウザのデータ消去やプライベートモードで履歴が消えることがあります。
- **CSVでの定期的なバックアップ**を強く推奨します。
- 「履歴」タブの **「全データ削除」** は会計履歴をすべて消去します（確認ダイアログあり・取り消し不可）。

## ファイル構成

```
register_c108/
├── README.md
└── docs/
    ├── index.html          # 画面（レジ / 履歴タブ、各モーダル）
    ├── style.css           # モバイル優先レスポンシブ
    ├── app.js              # ロジック（会計フロー・保存・CSV）
    ├── products.js         # 事前定義商品データ（編集対象）
    ├── sw.js               # Service Worker（オフライン動作）
    ├── manifest.webmanifest# PWAマニフェスト
    └── images/             # 商品写真プレースホルダ / アプリアイコン
```

## 技術メモ

- フレームワーク不使用（Vanilla JS）、外部CDN依存なし。
- 金額計算はすべて整数（円）で行い、浮動小数点誤差を回避。
- Service Worker はバージョン付きキャッシュ（`CACHE_v1`）で、更新時に旧キャッシュを破棄。
